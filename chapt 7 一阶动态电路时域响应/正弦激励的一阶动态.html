物理原理分析

一阶 RL 电路在正弦激励下的全响应由稳态分量和瞬态分量叠加而成：

i(t) = iss(t) + itr(t) = (A/Z)·sin(ωt + φ − φz) − (A/Z)·sin(φ − φz)·e−t/τ

其中瞬态分量的初始幅值由 sin(φ − φz) 决定。这个差值直接决定了过渡过程的剧烈程度和持续时间。

Case 1：φ = φz（无过渡过程）

当激励初相位恰好等于电路阻抗角时，sin(φ − φz) = 0，瞬态分量完全消失。 换路瞬间电流直接达到稳态值，过渡时间为零。 这是理想的无过渡过程条件，工程上称为"换路匹配"。

Case 2：φ = φz ± 90°（过渡过程最长）

当相位差为 ±90° 时，sin(φ − φz) = ±1，瞬态分量初始值达到最大。 此时全响应与稳态响应偏差最大，需要经过 约 4~5τ 才能衰减到可忽略的程度。 这是过渡过程最剧烈、持续时间最长的情形。

Case 3：中间相位（过渡过程中等）

当相位差介于 0° 和 90° 之间时，瞬态分量初始值介于 0 和最大值之间。 过渡过程的剧烈程度和持续时间也处于中间水平，约 2~3τ 后基本进入稳态。
