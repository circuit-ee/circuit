图一：各元件电压与支路电流波形
u(t) 电源电压
i(t) 支路电流
uR(t) 电阻电压（与电流同相）
uL(t) 电感电压（超前电流90°）
uC(t) 电容电压（滞后电流90°）
电压电流图解读 电阻电压 uR 与电流 i 同相位；电感电压 uL 超前电流 90°；电容电压 uC 滞后电流 90°。

三元件电压之和等于电源电压 u = uR + uL + uC（相量合成）。

当 XL = XC 时发生串联谐振，uL 与 uC 幅值相等相位相反，互相抵消，总阻抗最小，电流最大。
图二：各元件功率波形
pR(t) 电阻瞬时功率
pL(t) 电感瞬时功率
pC(t) 电容瞬时功率
P 有功功率（平均值）
p(t) 总瞬时功率
功率图解读 电阻瞬时功率 pR ≥ 0，平均值即为有功功率 P（红色虚线）。

电感和电容的瞬时功率 pL、pC 正负交替，平均值为 0，幅值对应无功功率 Q。

总瞬时功率 p(t) = pR + pL + pC，反映电源实际输出的瞬时功率。当 p > 0 时电源向电路供能，p < 0 时电路向电源回馈能量。
图三：各元件储能波形
WL(t) 电感储能 ½Li²
WC(t) 电容储能 ½Cu²C
W(t) 总储能
WR(t) 电阻耗能累积
W源(t) 电源发出能量累积
能量图解读 电感储能 WL 与电流平方成正比，电容储能 WC 与电容电压平方成正比，两者均以 2ω 频率在 0~Wmax 间振荡。

当 p > 0 时能量增加，p < 0 时能量减少（回馈电源）。电阻能量持续累积（转化为热能）。

电源发出的能量 W源 为总瞬时功率的积分，反映电源向电路提供的净能量。谐振时总储能 W = WL + WC 保持恒定，能量在 L 与 C 之间往返交换，电源只需补充电阻损耗。
