① 1000 kV 特高压：空载末端电压升高

工程背景

特高压交流线路对地电容巨大，空载时电容电流流过线路电感，在末端产生压升—— 这叫 费兰蒂效应（Ferranti Effect）。线路越长，末端电压越高。

第9章工具：π 型等效电路

把分布参数线路等效为 π 型：

XL = x · l     B = b · l     ΔU / U1 ≈ XL · B · U1 / 2

其中 x = 0.25 Ω/km，b = 4.5 μS/km 为 1000 kV 单回线单位长度参数。

📐 集总 π 型什么时候能用？

判据：工频 λ = 6000 km，工程上要求 l ≤ λ/20 = 300 km 时， 集总 π 型误差 < 2%，可放心使用。

因此下面滑块限定在 50 ~ 300 km（集总合法区）。超过 300 km 见第④页。

💡 工程措施：当 ΔU/U₁ 接近 10%（约 300 km 处），必须投入 高压并联电抗器吸收线路充电功率，否则末端电压越限，威胁设备绝缘。

② 特高压受端电网：无功缺口与电压支撑

工程背景

西北新能源大基地经 1000 kV 线路向华东送电。送端线路发出容性充电功率 QC， 受端负荷（异步电机群）吸收大量感性无功 QL，造成受端电压跌落。

③ 两区域电网小扰动：特征值判稳

工程背景

两大机群经弱联络线相连（如川渝—华中东），负荷扰动后会出现 0.2 ~ 0.8 Hz 区域间低频振荡。第9章的节点导纳矩阵 + 第5章特征值， 就是判断这类稳定性的最小工具集。

第9章 + 第5章工具

Y = [ jB₁   −jB₁₂   0 ; −jB₁₂   j(B₁₂+B₂)   −jB₂₃ ; 0   −jB₂₃   jB₃ ]    λ = σ ± jωd

σ < 0 → 阻尼正，扰动衰减；σ > 0 → 失步，需加 PSS / 调相机。

💡 B12 越小 → 联络越弱 → σ 越接近 0 → 区域间振荡越明显。 这正是大三《电力系统分析》低频振荡一章的起点。

④ 集总 π 型到底能用多远？

原理

线路是分布参数系统，集总 π 型只是它的小长度近似。判断标准：

λ = v/f = 3×10⁸ / 50 = 6000 km    l ≤ λ/20 = 300 km → 集总可信

三种算法

方法公式适用长度
集总 π 型 ΔU/U₁ ≈ (ωL'·ωC'·l²)/2 l ≤ 300 km 本页案例1
修正 π 型（GB/T 22389） Y' = Y · tan(βl/2)/(βl/2) 300 ~ 600 km 特高压常用
分布参数（精确） U₂/U₁ = 1 / cos(βl) > 600 km 必须分布建模
