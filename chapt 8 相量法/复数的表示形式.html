4 种等价表示

1
代数形式
Algebraic / Cartesian
直角坐标
z = 3.0 + 2.0i

突出要素：实部 a（水平分量）和 虚部 b（垂直分量）

Re(z) = a Im(z) = b
2
几何/向量形式
Geometric / Vector
有向线段
OZ→ = (3.0, 2.0)

关键特征：起点必须为原点O，终点为Z(a,b)的平面向量

几何意义：复数集 ℂ 与复平面上以原点为起点的向量集合一一对应 [^1^]
3
三角形式
Trigonometric / Polar
极坐标基础
z = 3.61(cos 0.59 + i sin 0.59)

突出要素：模 r（向量长度）和 幅角 θ（与实轴夹角）

r = |OZ→| θ = Arg(z)
4
指数形式
Exponential / Euler
欧拉公式
z = 3.61ei0.59

最简洁形式，乘除运算极为方便：模相乘，幅角相加

欧拉恒等式：eiπ + 1 = 0

表示法转换关系

📐
直角坐标 ↔ 极坐标
a = r·cosθ,   b = r·sinθ  |  r = √(a²+b²),   θ = arctan(b/a)
➕
向量运算的几何意义
加法遵循平行四边形法则；乘法对应旋转+伸缩 [^2^]
1:1
一一对应关系（三联对应）
复数 z = a+bi  ↔  复平面上的点 Z(a,b)  ↔  向量 OZ→
注：仅与以原点为起点的向量一一对应，非全体向量 [^6^]
