1 电路模型与KVL方程

考虑一个由电阻 R 和电容 C 组成的串联电路，接入正弦交流电源：

us(t) = Um cos(ωt)

KVL 根据基尔霍夫电压定律，回路电压满足：

uR(t) + uC(t) = us(t)

元件 代入元件特性方程：

uR = R·i
电阻：欧姆定律
i = C·duC/dt
电容：微分关系
s uR uC

📋 时域微分方程

RC·duC/dt + uC = Um cos(ωt)

这是一个一阶线性非齐次微分方程

2 时域方程求解

通解结构

非齐次方程的解 = 齐次解 + 特解

uC(t) = uCh(t) + uCp(t)
①

齐次解（暂态响应）

uCh = A·e-t/τ,   τ = RC
②

特解（稳态响应）

设特解形式与激励同频率：

uCp = UCm·cos(ωt + φ)

关键观察： 稳态解也是同频率的正弦量，只是幅度和相位发生了变化！

代入求解过程

将特解代入微分方程：

-RCωUCmsin(ωt + φ) + UCmcos(ωt + φ) = Umcos(ωt)

利用三角恒等式合并：

√(1+(RCω)²)·UCm·cos(ωt + φ + θ) = Umcos(ωt)

其中 tan θ = ωRC

🎯 稳态解结果

幅度关系

UCm = Um / √(1+(ωRC)²)

相位关系

φ = -arctan(ωRC)

电容电压滞后电源电压，滞后角取决于频率和RC乘积

3 稳态响应可视化

观察暂态过程如何衰减，最终只留下与激励同频的稳态正弦响应

参数调节

快 0.5s 慢
低频 2 rad/s 高频

物理意义

  • ● 红色：电源电压 us(t)
  • ● 蓝色：电容电压 uC(t)
  • --- 绿色虚线：稳态分量
  • --- 紫色虚线：暂态分量

稳态特征

当 t > 5τ 时，暂态分量衰减至初始值的0.7%以下，电路进入正弦稳态。 此时 uC(t) 是与 us(t) 同频率的正弦波。

4 时域到相量域的变换

利用"同频正弦量"这一特点，将微分运算转化为代数运算

🔄 相量变换定义

对于正弦量 u(t) = Um cos(ωt + φ)，定义其相量为：

U̇ = Um∠φ = Um·ejφ

包含幅度和相位信息，省略了时间因子 ejωt

⚡ 微分运算的相量对应

📍

时域：微分运算

du/dt  ⇒  jω·U̇
↓
🎯

相量域：代数乘法

d/dt  ↔  jω

微分 → 乘以 jω（幅度×ω，相位+90°）

💡 关键优势

将微分方程转化为复数代数方程， 避免了求解微分方程的复杂过程，直接通过复数运算得到幅度和相位关系。

📊 方程形式对比

🎯 电压相量三角形

KVL相量形式：U̇R + U̇C = U̇s

C UCm U̇R URm U̇s Um φ 滞后角 İ 与U̇R同相 U̇C滞后U̇s角度φ，U̇R超前U̇C 90°
电压三角形：U̇R + U̇C = U̇s
Um² = URm² + UCm²
tan|φ| = URm/UCm = ωRC = ImR / (Im/ωC) = R/XC

电容电压 U̇C 滞后电源电压 U̇s，滞后角 φ = -arctan(ωRC)

电阻电压 U̇R 与电流 İ 同相，超前电容电压 90°

阻抗三角形与电压三角形相似，阻抗角等于电压相位差

🎓 总结

  • 1. 正弦稳态下，所有电压电流都是同频正弦量
  • 2. 相量将时域微分转化为频域代数：d/dt → jω
  • 3. 电容表现为复阻抗：ZC = 1/(jωC) = -jXC
  • 4. 电压相量三角形直观展示KVL的相量关系
