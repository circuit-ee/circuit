第10章 含有耦合电感的电路

互感 · 反射阻抗 · 空心变压器 · 去耦等效 —— 系统级工程案例

📖工程背景：为什么研究耦合电感？
  • 电力变压器：特高压变电站主变（1000kV/500kV），高低压绕组磁耦合，k≈0.98
  • 无线充电：电动汽车 Qi 标准 11kW，原副边松耦合 k≈0.2~0.4
  • 互感器：电流互感器 CT，把大电流"感应"成小电流供保护测量
  • 感应加热：电磁炉 20~40kHz，锅底涡流直接发热
所有这些设备的数学内核，都是同一组互感方程。

耦合电感：两个线圈"磁牵手"

线圈1电流变化 → 磁通一部分穿过线圈2 → 在线圈2感应电压。反之亦然。

u₁ = L₁ di₁/dt + M di₂/dt
u₂ = M di₁/dt + L₂ di₂/dt

① 互感 M 与耦合系数 k

k = M / √(L₁ · L₂)    0 ≤ k ≤ 1

k 越小 → 磁耦合越松（空心线圈，无线充电）；k 越大 → 耦合越紧（铁芯变压器 k≈0.95+）。

② 同名端（·）的意义

同名端标出感应电压的极性方向，是列 KVL 方程时"正负号"的裁判。

实验测定法（邱关源习题常考）：

🔬 同名端实验：把两线圈串联接到直流电源，用万用表测总电感。
顺接（异名端相连）：L_顺 = L₁ + L₂ + 2M
反接（同名端相连）：L_反 = L₁ + L₂ − 2M
→ M = (L_顺 − L_反) / 4
这就是工程上实际测量耦合系数的方法。
💡 第10章的本质：把看不见的"磁耦合"，变成电路里看得见的等效阻抗。

③ 去耦等效（T型等效）

对互感 M，可等效为三个独立电感：

同名端共端：支路1 = L₁−M    支路2 = L₂−M    公共支路 = M
异名端共端：支路1 = L₁+M    支路2 = L₂+M    公共支路 = −M

公共支路电流：同名端共端时为 i₁−i₂；异名端共端时为 i₁+i₂。

⚡工程背景：特高压直流输电换流站
  • 真实工程：向家坝—上海（±800kV, 2071km）、锦屏—苏南（±800kV, 2059km）
  • 核心设备：换流变压器，网侧绕组接交流 1000kV，阀侧分裂绕组接 ±400kV 直流
  • 谐波问题：12脉动换流产生 12k±1 次谐波（11th, 13th, 23th, 25th…），必须隔离
  • 解决方案：利用分裂绕组间的强耦合（k≈0.9），让谐波"被困"在阀侧局部回路
模型说明：下面为双绕组等效简化模型（真实换流变为三绕组：网侧+两阀侧）。

特高压换流站：多绕组耦合 + 谐波滤波

±800 kV 直流输电，整流侧换流变压器网侧 1000 kV、阀侧 ±400 kV，分裂绕组强耦合。

简化电路模型（双绕组等效）

M = k · √(L_v1 · L_v2)    Z_ref(h) = (hωM)² / Z_harm

工程逻辑：12脉动换流产生 12k±1 次谐波。调分裂绕组耦合系数 k → 改 M → 改反射阻抗 → 把特定次谐波"困"在阀侧局部回路，不让它窜入交流电网。

⚠️ k 越大 → 谐波隔离越好 → 但短路应力越大。工程折中取 k≈0.85~0.95。
这也是换流站占地巨大的原因——大片场地留给耦合滤波电抗器组。
注：Z_harm = 1.0 + h×0.8 为示意量级模型，真实值需查换流变短路阻抗参数。

平波电抗器（直流侧大互感元件）

串联在直流母线，±800kV 工程典型值 L_dc ≈ 75 mH（如特变电工 PKGKL-800-5000-75）：

ΔI = U_ripple / (ω_dc · L_dc)

L_dc 越大 → 纹波越小 → 但动态响应越慢。这是另一个"耦合电感"设计权衡。

🔥工程背景：1000MW 超超临界机组轴系
  • 真实工程：华能玉环电厂（1000MW, 26.25MPa/600℃）、泰州电厂二次再热
  • 轴系结构：高压缸→中压缸→低压缸→发电机→励磁机，5~6 个转子串联
  • 事故警示：1970年美国 Mohave 电厂，次同步谐振(SSR)导致大轴断裂！
  • 物理本质：多转子经联轴器耦合，和互感方程完全同构（J↔L, κ↔M）
启机时必须快速"过临界转速"，否则共振振幅失控。

1000 MW 超超临界机组：轴系扭转耦合

锅炉→高压缸→中压缸→低压缸→发电机→励磁机，多转子经刚性/柔性联轴器相连。

简化力学模型（多自由度扭转）

J_i θ̈_i + κ_i(θ_i − θ_{i+1}) + κ_{i-1}(θ_i − θ_{i-1}) = T_i

与互感方程同构：J ↔ L，κ ↔ M，θ ↔ ψ（磁链），T ↔ u

💡 κ 大 → 转子"抱得紧" → 模态频率高 → 易避开工频
κ 小 → 分段自由 → 低频扭振（0.5~2 Hz）→ 次同步谐振风险
启机必须"过临界转速"——这正是模态频率的实际意义

回热系统热耦合（热网络互感）

各级高压加热器疏水焓 h_i 受相邻级影响：

h_i = a_i · h_{i-1} + M_th · h_{i+1} + Q_i

M_th 是疏水换热的"热互感"系数，和电磁互感 M 数学形式完全一样。

🧮工程背景：反射阻抗的典型应用
  • 无线充电：手机/电动车 Qi 标准，原边线圈通电 → 副边感应 → 反射阻抗让原边"感知"负载
  • RFID 电子标签：读卡器线圈和标签线圈松耦合，标签吸收能量靠的就是反射阻抗
  • 感应加热：电磁炉锅底相当于副边短路的"单匝线圈"，反射回原边的阻抗决定加热功率
核心发现：副边接纯电阻 → 在高Q/高频近似下，反射回原边的也是纯电阻。

反射阻抗：负载"穿越"到原边

这是第10章最"反直觉"的结论：副边接个电阻，原边看过去多了一个电阻。

简化电路模型（空心变压器）

Z_ref = (ωM)² / Z₂₂    Z₂₂ = R₂ + jωL₂ + Z_L

严格公式：Z_ref = (ωM)² / (R₂ + R_L + jωL₂)，是一个复阻抗（既有电阻也有感抗）。
高Q/高频近似（ωL₂ ≫ R₂ + R_L 时）：虚部可忽略，Z_ref ≈ (ωM)² / (R₂ + R_L) 才是纯电阻。
原网页直接说"纯电阻"不够严谨——条件是副边感抗远大于电阻（无线充电/RFID 通常满足）。

✅ 工程应用：无线充电 / RFID / 感应加热——都是靠"反射阻抗"把能量从原边传到副边。
✅ 条件回顾：只有 ωL₂ ≫ R₂+R_L（高Q线圈、工作频率足够高）时，反射阻抗才近似纯阻。
