耦合电感在三角波 / 脉冲波 / 正弦波激励下的响应

标准双端口电路模型 · 变量参考方向标注 · 原边电流 i₁(t) / 副边电流 i₂(t) / 副边负载电压 u_RL(t)

① 电路模型（标准双回路 · 参考方向）

回路方程（关联参考方向，同名端同侧）：

u₁(t) = R₁·i₁ + L₁·di₁/dt + M·di₂/dt     0 = R₂·i₂ + L₂·di₂/dt + M·di₁/dt + R_L·i₂

参考方向约定：i₁ 由原边上端（·端）流入，i₂ 由副边上端（·端）流出；两电流均从同名端一侧进入各自绕组时，产生的互感磁通方向相同。u_RL 以负载上端为「+」、下端为「−」，故 u_RL = R_L·i₂（i₂ 参考方向下正下负）。

数值校验：正弦稳态下，用相量法反射阻抗 Z_in = R₁+jωL₁+ω²M²/(R₂+R_L+jωL₂) 解析计算 I₁ 幅值，与本页面数值解稳态幅值对比，二者应一致（见仿真后下方）。

③ 仿真结果（时域响应 · 三色分图）

原边电流 i₁(t)（橙）。电感电流不能突变，呈积分/滞后形态；正弦稳态下与 u₁ 有相移。
副边电流 i₂(t)（绿）。由互感电动势 e₂=M·di₁/dt 驱动，对三角波拐点、脉冲跳变沿最敏感。
副边负载电压 u_RL(t)=R_L·i₂（紫）。反映负载实际获得的电压响应。
校验区：仿真完成后此处显示「相量解析 I₁幅值 vs 数值解稳态 I₁幅值」对比。

④ 物理规律小结

  • 互感电动势 e₂ = M·di₁/dt（极性由同名端决定）。副边响应正比于原边电流变化率，故对三角波拐点、脉冲跳变沿产生明显尖峰。
  • 耦合系数 k 越大（M 越大），能量传递越强，i₂、u_RL 幅值越大；k=0 时副边无响应（可拖动滑块验证）。
  • 正弦稳态：i₁、i₂、u_RL 均为同频正弦并存在相移；本页面用相量反射阻抗解析解交叉校验数值解，二者一致。
  • 脉冲激励：每个跳变沿在副边产生尖峰，体现耦合电感"隔直流、通交流/突变"的特性。
