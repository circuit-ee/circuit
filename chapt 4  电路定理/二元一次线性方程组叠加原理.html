线性方程组解的叠加原理

叠加原理：对于线性方程组 Ax = b，如果 b = b₁ + b₂ + ... + bₙ，那么方程组的解 x = x₁ + x₂ + ... + xₙ，其中 Axᵢ = bᵢ。

步骤 0: 原始线性方程组

2x + y = 5
x - 3y = -8   或   2 1
1 -3 x
y = 5
-8

解: x = 1, y = 3

步骤 1: 将 b 分解为 b₁ + b₂

方程组 1: Ax = b₁

2x + y = 5
x - 3y = 0

解: x₁ = 15/7, y₁ = 5/7

+

方程组 2: Ax = b₂

2x + y = 0
x - 3y = -8

解: x₂ = -8/7, y₂ = 16/7

步骤 2: 验证叠加原理

根据叠加原理，原方程组的解应该等于两个分解后方程组解的和：

x = x₁ + x₂ = 15/7 + (-8/7) = 7/7 = 1

y = y₁ + y₂ = 5/7 + 16/7 = 21/7 = 3

验证:
x₁ + x₂ = 15/7 + (-8/7) = 1
y₁ + y₂ = 5/7 + 16/7 = 3

步骤 3: 一般情况下的叠加原理

对于任意线性方程组 Ax = b，其中 b = b₁ + b₂ + ... + bₙ：

  1. 分别求解 Axᵢ = bᵢ，得到解 xᵢ
  2. 原方程组的解为 x = x₁ + x₂ + ... + xₙ
  3. 这个性质只对线性方程组成立
数学表达：
如果 Ax = b，且 b = Σbᵢ，那么 x = Σxᵢ，其中 Axᵢ = bᵢ
