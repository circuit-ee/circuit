自然等位点

定义：电路因内在对称或比例关系而自然形成的等电位节点，无需外部连接。

当电桥平衡时，节点 B 与 D 自然等电位。

等效电阻（利用自然等位点）
Req = (R₁+R₃) ∥ (R₂+R₄) = 10.0 Ω

原理：B、D 等电位 → 桥臂无电流 → 可断开桥臂 → 电路简化为两并联支路

强制等位点

定义：用理想导线（零电阻）将两个节点强制连接，使其电压相等，不论原电路状态如何。

短接后，B 与 D 被强制为同一电位。

等效电阻（利用强制等位点）
Req = (R₁∥R₂) + (R₃∥R₄) = 10.0 Ω

原理：B、D 短接 → R₁∥R₂ 与 R₃∥R₄ 串联 → 电路等效变换

对比总结

自然等位点

  • 由电路结构和对称性自然产生
  • 等位点之间无电流流动
  • 可安全断开（移除导线）简化电路
  • 不改变电路的电气特性

强制等位点

  • 通过外部短路线人为强制连接
  • 可能改变原电路的电流分布
  • 用于 Y-Δ 变换等电路简化
  • 是电路等效变换的重要工具
