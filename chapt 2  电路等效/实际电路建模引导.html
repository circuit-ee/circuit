实际工程电路 → 理想电路模型

从真实电子器件构成的实际工程电路出发，梳理 四类 / 十四种 常见建模方法，搞清"用什么建模方法、模型落到哪类元件"。面向电气工程及其自动化 / 自动化专业。

一、建模的核心问题

真实电路（如同步 Buck）到可仿真 / 可分析，要经历"物理实现 → 理想电路模型"的建模。建模方法取决于两件事：

手头有什么信息 × 想要什么精度 / 速度 → 选建模方法 → 集总 / 分布 / 受控源 / 查表

尺寸—波长判据：ℓ/λ < 0.1 可集总；ℓ/λ ~ 0.25 进入过渡；ℓ/λ ≥ 0.25 建议分布（传输线）模型。此为工程经验法则，非硬边界。

二、四类建模方法总览

按"抽象程度 × 信息来源"归类，同一 Buck 可在不同视角下选用不同方法。

① 黑箱类
以外特性 / 端口响应建模型，不关心内部物理。
  • 外特性（黑箱）建模
  • 行为建模（LUT/S 参数）
  • 二端口（Z/Y/S/ABCD）建模
② 白箱类
由器件物理方程构造可计算的等效模型。
  • 物理原理建模（BSIM）
  • 状态空间建模
  • 平均 / 大信号平均建模
③ 尺度类
由几何尺寸与波长关系决定模型形态。
  • 集总等效建模
  • 分布参数建模
  • 降阶模型 ROM（场→路）
④ 多域 / 鲁棒类
跨物理场、工艺鲁棒性与失效分析。
  • 电热耦合建模
  • 混合多域建模
  • 容差 / 故障建模

五、建模方法选择指南

按"已知信息"选

有 datasheet/伏安曲线 → 外特性；有几何/材料与工艺 → 物理原理(BSIM)；有实测多频响 → S 参数/行为(LUT)；只有端口响应 → 二端口；有 FEM 场仿真 → ROM 降阶。

按"仿真目的"选

环路补偿/小信号 → 集总+平均+状态空间；高频/RF → 分布+S 参数；大信号/瞬态精度 → 物理原理(BSIM)；温升/寿命 → 电热耦合；级联系统 → 二端口。

📌 没有绝对最优的模型，只有"够用且高效"的模型。模型是物理系统的理想化近似，选取要在精度 × 仿真速度 × 可用信息之间权衡。
