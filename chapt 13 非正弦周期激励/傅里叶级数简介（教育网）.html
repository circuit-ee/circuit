傅里叶级数的来历

一段跨越两百年的数学传奇

1
1807年 · 巴黎科学院

法国数学家 约瑟夫·傅里叶 在研究热传导问题时，提出了一个惊人的猜想： 任何周期函数，都可以表示为正弦和余弦函数的无穷级数之和。

"热的分析理论" —— 这篇论文最初被拉格朗日拒绝发表，因为它太超前了。

2
核心思想

傅里叶发现，复杂的热分布（温度随位置变化）可以分解为简单正弦波的叠加。 这类似于：

白光通过棱镜分解成七色光谱 → 复杂信号分解为简单正弦波

3
数学突破

1822年，傅里叶出版了《热的分析理论》，正式建立了傅里叶级数的数学框架。 这一理论不仅解决了热传导问题，更成为现代 信号处理、图像压缩、量子力学 的基石。

傅里叶级数公式

用数学语言描述"分解与重构"

周期函数 f(x) 的傅里叶展开
f(x) = a02 + ∞∑n=1 ( an cos2πnxT + bn sin2πnxT )
或等价地写成
f(x) = a02 + ∞∑n=1 ( an cos nω0x + bn sin nω0x )
直流分量
a0 = 2T∫T0 f(x) dx

函数在一个周期内的平均值

余弦系数
an = 2T∫T0 f(x) cos nω0x dx

第 n 个余弦波的"权重"

正弦系数
bn = 2T∫T0 f(x) sin nω0x dx

第 n 个正弦波的"权重"

参数含义

T 周期 —— 函数重复的最小间隔
ω₀ 基频 —— ω₀ = 2π/T，最低频率分量
n 谐波次数 —— n=1 基波，n=2 二次谐波...
∞ 无穷级数 —— 理论上需要无限项才能精确重构

直观理解

三个视角，让你"看见"傅里叶级数

1

积木视角：正弦波是基本积木

想象你要用乐高积木搭建一座复杂的城堡。傅里叶级数告诉我们：任何周期函数，都可以用不同大小、频率的正弦波"积木"搭建出来。

2

正交基视角：像坐标投影一样分解

在三维空间中，任何向量都可以分解为 x、y、z 三个方向的投影。傅里叶级数做了一件类似的事： 将函数"投影"到无穷多个正交的正弦/余弦基函数上。

什么是"正交"？

两个函数正交，意味着它们在一个周期内的"内积"为零：

∫T0 sin(nω0x) · sin(mω0x) dx = 0   (n ≠ m)

这就像三维空间中 x 轴和 y 轴互相垂直一样。正因为正交，我们才能独立地求出每个频率分量的系数，互不干扰。

n = 1 | m = 2
当 n ≠ m 时，积分结果趋近于 0（正交！）
3

内积视角："相关性"决定系数大小

系数 aₙ 和 bₙ 的计算公式，本质上是在问："原函数 f(x) 和第 n 个正弦/余弦波有多像？"

系数公式的本质
an = ⟨f, cos nω0x⟩⟨cos nω0x, cos nω0x⟩
分子 = 函数 f 与基函数的"相关性"（内积）
分母 = 基函数的"自身长度"（归一化因子）

通俗理解

  • • 如果 f(x) 长得很像 sin(2x)，那么 b₂ 就会很大
  • • 如果 f(x) 和 cos(5x) 完全不搭边，那么 a₅ 就接近 0
  • • 每个系数就像"投票"，告诉我们原函数中包含多少该频率的成分

一句话总结

傅里叶级数告诉我们：再复杂的周期现象，也不过是简单正弦波的合唱。

通过正交基的内积投影，我们可以精确地"听出"每一个声部的音量——这就是系数 aₙ 和 bₙ 的物理意义。
"自然界最深刻的真理，往往以最简洁的数学形式呈现。" —— 傅里叶
