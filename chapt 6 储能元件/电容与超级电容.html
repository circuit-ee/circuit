电容器技术对比

超级电容 vs 普通电容

普通电容器

极板间距: d = 微米级

储能机制: 静电感应

电容值: μF ~ mF

超级电容器

有效距离: d = 纳米级 (双电层)

储能机制: 双电层 + 赝电容

电容值: F ~ kF

物理模型公式

普通电容

C = ε₀εᵣA/d

平行板电容器模型

超级电容

C = εA/dEDL

双电层模型 (dEDL ≈ 1nm)

关键区别： 超级电容利用纳米级双电层和多孔结构极大增加了比表面积A，同时减小了有效距离d

伏安特性 (V-I Characteristics)

普通电容

超级电容

普通电容特性

  • • 理想情况下：I = C(dV/dt)
  • • 充放电曲线为指数函数
  • • 时间常数 τ = RC 决定充放电速度
  • • 等效电路：理想电容 + ESR

超级电容特性

  • • 等效电路更复杂：包含多孔电极传输线模型
  • • 存在漏电流和自放电现象
  • • 充放电曲线近似线性（大电容特性）
  • • 等效串联电阻(ESR)通常更低

超级电容器结构

双电层电容 (EDLC)

  • • 比表面积: 1000-3000 m²/g
  • • 孔径分布: 微孔(<2nm) + 中孔(2-50nm)
  • • 隔膜: 离子透过，电子绝缘

赝电容材料

金属氧化物 (RuO₂, MnO₂)

表面快速氧化还原反应

比电容: 100-1000 F/g
导电聚合物 (PEDOT, PANI)

掺杂/去掺杂过程储能

比电容: 200-500 F/g
复合材料

碳材料 + 赝电容材料协同
