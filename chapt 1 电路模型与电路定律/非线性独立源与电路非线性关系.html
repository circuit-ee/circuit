核心结论

电路是否线性，由「结构 + 元件特性」决定，与独立源的大小、波形都无关。

判断一个电路是不是线性电路，只看两件事：

组成是否决定线性说明
电阻 / 电感 / 电容（线性元件）✅ 决定R,L,C 为常数 → 线性；R(i)=R₀+αi → 非线性
独立电压源 / 电流源（大小、直流、正弦、方波…）❌ 不决定只是输入信号，改它只改响应幅度/形状
受控源（控制关系线性，如 i=g·v）✅ 决定（仍线性）属于结构一部分
受控源（控制关系非线性，如 i=g·v²）✅ 决定（非线性）整体非线性
💡 关键区分
独立源的大小 → 只改响应幅度
独立源的波形（方波/锯齿/噪声）→ 只改响应形状，不改变电路线性属性
只有元件/结构（含受控源控制关系）非线性 → 电路才非线性

类比：弹簧秤（线性元件）挂 1kg 或 5kg（独立源大小不同），读数同比变化，秤本身还是线性的；换成橡皮筋（非线性元件），哪怕只挂 1kg，它也非线性。

结构决定线性 · RL 串联电路

拖 Uₛ：3D 里电池电压变、电流同比变，但 电阻 R、电感 L 没变 → 电路仍是线性，响应曲线形状不变。

时域电流波形 i(t)

线性 RL：i(t)=(Uₛ/R)(1−e^(−t/τ)), τ=L/R 非线性对照（R(i)=R₀+αi）：饱和弯曲曲线
改 Uₛ → 蓝线整条同比缩放（形状不变）；把 R 改成 R(i)=R₀+αi（结构变）→ 红线弯曲 → 这才是非线性电路。

独立源只改幅度，不改斜率（线性判据）

改 Uₛ → 绿点沿同一条直线滑动（斜率 1/R 不变）→ 源只改工作点幅度
改 R → 整条直线绕原点转动（斜率变）→ 结构元件才决定线性/斜率

叠加性 / 齐次性验证

叠加定理 对电路成立：i(U₁+U₂) = i(U₁)+i(U₂)；
但 对源信号本身不成立（如方波源 square(t) 不是线性算子）—— 这不改变电路仍是线性电路。
