📌 一句话先记住

电压 = 电位差（UAB=VA−VB），它描述"两点之间"。但当电路有几十上百个节点时，给每个节点标一个电位 V（相对同一个零点），比两两列举电压简单得多；而电位是相对值，必须先把电位零点定下来，才有意义。

UAB = VA − VB　｜　电位零点：人为规定 V0 = 0 V

① 为什么有了电压，还要引入"电位"？

电压是"两点间的高度差"，电位是"每点的海拔"。两者本质相同，但描述对象不同。

若电路有 n 个节点：两两电压共有 C(n,2) 个；而给每个节点一个电位只要 n 个数，任意电压一减即得。

例：100 个节点 → 电压需记 4950 个，电位只要 100 个。

🏔
海拔类比

电压（电位差）

描述两点之间，如"泰山比济南高 1000 m"。关心的是"差"。

电位

描述某一点相对零点的数值，如"泰山海拔 1545 m"。关心的是"点的值"。

② 为什么必须引入"电位零点"？

电位是相对值：选不同的零点，各点电位数值会变，但任意两点电压（电位差）始终不变。点击下方按钮切换零点，观察数值。

结论：电位零点是一个人为约定的参考基准，用来给"电位"这个相对量赋予确定的数值，方便计算、测量与标注。

③ 电位 与 电势 的联系与区别

电位与电势在数值上是同一个物理量，只是学科语境不同：物理学常用"电势（φ）"描述电场中某点的属性；电路工程常用"电位（V）"表示节点相对参考点的电压值。下面从"联系"和"区别"两方面说明。

🔗 联系（数值上统一）

同一物理量的两种叫法

物理学称"电势 φ"，电路工程称"电位 V"。两者单位都是伏特(V)，描述同一电场属性。

公式一致

VA = φA − φ0。选定参考点 φ0=0 后，电位 VA 与电势 φA 在数值上一致。

电位（V）是电势（φ）在电路工程中的"实用化表述"　→　数值体系完全统一

📍 补充：电位零点 vs 电势零点

两者本质也是"同一参考约定"的两种语境：电势零点是物理学中给电势 φ 选的参考点（常取无穷远或大地）；电位零点是电路工程里给电位 V 选的 0 V 参考节点（常取 GND/机壳/指定节点）。选定后两者数值相同，只是工程上更强调"电路节点"这一具体对象。

↔️ 区别（视角与习惯不同）

对比项电势（物理视角 φ）电位（工程视角 V）
所属学科电磁学 / 物理学电路理论 / 电子工程
研究对象电场中某点的电势属性电路节点相对参考点的电压值
参考点习惯常取无穷远处或地球为电势零点常取电源负极(GND)、机壳或指定节点为零点
选取动机满足物理场的边界条件便于电路分析、标注与测量
典型表述"取无穷远为电势零点""该引脚电位为 3.3 V（相对 GND）"

一句话总结：电势是物理上的原始概念，电位是它在电路工程中的实用叫法——本质相通，参考点的选取习惯和表述方式不同。而"电位零点"正是为电位这个相对量人为规定的 0 V 参考点（见章节 ②）。

④ 电位在工程中的应用（4 大好处）

📐 简化电路图

所有 GND 符号代表同一点，不必把回线全部画回电池；芯片手册只标引脚电位。

🔌 示波器直读

黑夹子接零点（GND），红夹子点到哪点，屏幕即显示该点电位，无需再算差。

🧩 模块对接

传感器输出 3.3 V、单片机识别 3.3 V——前提是两者共用同一零点（共地）。

🛡 安全与抗干扰

把零点接大地泄放漏电/雷击；或把零点隔离（浮地）避免地环路干扰。

📐 接地方式速记（PCB 设计）：低频（<1 MHz）用单点接地（所有地汇到一点，避免共阻抗耦合）；高频（>10 MHz）用多点接地（就近接到接地平面，减小引线电感）；数/模地分开后在电源入口单点汇合。这是大二模电/PCB 设计常考的工程要点。

⑤ 工程中常见的电位零点种类、符号与区别

🔋 电源地（Power / Signal GND）

符号 ▽（倒三角）或 GND / Vss

是什么

电源负极 / 电流公共回流节点，原理图上所有 GND 符号构成同一网络（全局 0 V 参考）。

用法

所有芯片地脚连到这里；说"某脚 3.3 V"默认相对此点。

🌍 保护大地（Earth / PE）

符号 ⏚（圆圈+三条递减横线）

是什么

经接地棒真正接入大地的零点，电位稳定≈0。

作用

防触电、泄放静电与雷击电流（三孔插座上孔为 PE）。

📦 机壳地（Chassis）

符号 ⟋⟋⟋（三条向下斜线，IEC 5020）

是什么

以设备金属外壳/机架作为零电位导体与屏蔽面。

注意

IEEE 315 指出：机壳相对大地可有相当高电位，需"接大地"须显式画出连接。

🎚 数字地 / 模拟地（DGND / AGND）

抗干扰

为何分开

数字电路开关噪声大，模拟电路（音频/传感器）敏感，共地会串扰。

接法

PCB 上分开布线，最后在电源入口单点汇合（单点共地/星型接地）。

🎛 虚地（Virtual Ground）

运放特性（非真接地）

是什么

运放负反馈时，反相端电位被"钳"到同相端电位（同相端接地时=0V）。

注意

依赖负反馈与高开环增益；运放一旦饱和/开环/过载即失效，不能当真实回流地。

✈️ 浮地（Floating）

隔离

是什么

系统内部有地，但整体不接大地（手机、笔记本、医疗仪器）。

折衷

隔离变压器断开地环路抗干扰；为防止静电积累，常在浮地与大地间并一阻值很大的泄放电阻。
